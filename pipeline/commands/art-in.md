# art-in

ユーザーが作った絵を受け取り、ゲームに入れる（S4）。

1. PCの `art/inbox/` にある絵の一覧を見る（device_list_dir）。名前が `art/ART_GUIDE.md` の一覧にあるかを確かめる。
2. 絵を Claude 側へ写し（device_stage_files）、`python3 scripts/art/process.py <受け取ったフォルダ>` で整える。
   出力は `src/assets/img/<名前>.webp`。表示された「※」（背景を消した、小さい、大きい）は、1枚ずつ見て確かめる。
3. 整えた絵を、実際の画面で見る（Claude 側でビルドして、旅・団員・勧誘の画面を撮る）。
   絵柄のずれ、縁の残り、切れ、向きを見て、気になるものはユーザーに伝える（作り直しの依頼文も添える）。
4. 通し操作テストを走らせ、記録する（`pipeline/rules/ui.md`「画面を変えたとき」）。
5. 記録（コミット）し、PCへ送り、`play` で公開する。入った絵の名前と、まだの絵の名前を伝える。
6. 受け取った元の絵は、PCの `art/inbox/` から `art/done/` へ移す（履歴には入れない。元の絵は残しておく）。
