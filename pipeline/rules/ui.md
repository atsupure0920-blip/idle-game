# 画面の決まり

対象: `src/ui/`、`src/battle/`、`src/debug/`

- UI（一覧、装備の比較、ポップアップ、ボタン）は HTML/CSS で作る。PixiJS は戦闘の表示の枠の中だけ。
- 操作できる要素と、値を表示する要素には `data-testid` を付ける。自動の通し操作テストがこれを使う。
- 画面はルールを持たない。値の計算は core に任せ、画面は結果を表示するだけ。
- 実際の時刻と保存領域を扱うのは `src/ui/` だけ。core へは値として渡す。
- 保存は、状態が変わったときと、画面が隠れるとき（`visibilitychange`、`pagehide`）に行う。
- 読めないセーブは、上書きする前に別名で残す。新しい版のセーブは上書きしない。
- ファイルの参照は相対パスにする（公開先の階層が変わっても動くように）。
- iPhone の縦持ちを基準にする。押す場所は 44px 以上。ノッチとホームバーの余白（safe-area）を取る。
- 画面に必ずビルドの番号を出す（確認用ビルド）。どのビルドを遊んでいるかを取り違えないため。
- デバッグ機能は `__DEBUG__` が真のときだけ動かす。公開用ビルドには入れない。
