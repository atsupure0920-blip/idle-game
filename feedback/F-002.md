# F-002 ボスを団員と同じ扱いにせず、別枠（ペット・召喚獣）にしたい

- 日付: 2026-10-11（build-4 を遊んだあと。ログは次に届く）
- 種別: 追加要望（契約書の変更を伴う。G3 より前なので、影響を示して承認を求める）
- 状態: 未対応（ログを待ってから、契約書の改訂案を出す）

## ユーザーの言葉（要約せずに残す）

- ボスが団員になる仕組みだが、他の団員と同じ扱いはやめたほうがいいと思った。
- それよりも、ペットとか、召喚獣的な別の枠としてチームに入れるほうがおもしろい。
- そうなると、ステージクリアごとに新しいボスが手に入り、その枠が高頻度で入れ替わってしまう。
  対策として、各ステージのボスの育成が無駄にならないような仕組みが欲しい。
  例: 各ボスが、ステータスを底上げしてくれるパッシブを持つペットになる。
- これにも問題がある。ボスにリソースを使うとき、強いボスに使うほうが強いので、そっちにばかり集中しそう。
  例: おひねりに加えて、各ボスごとに専用のレベルアップ素材を用意する。プレイヤーから見ると
  「その専用素材がたまったら、そのボスのレベルを、おひねりと合わせて上げる」という形にする。

## 影響（Claude の見立て）

- 契約書の決定1（ボスが改心して入団する）の中身が変わる。「入団」ではなく「相棒になる」。
- 決定2（編成は4人）に、相棒の枠が足される。決定4（団員11人 = 人間7 + 魔物4）は、団員7人 + 相棒4体になる。
- 決定7（通貨は、おひねりとチケットだけ）が変わる。ボスごとの専用素材が増える。
- 仕組みの数が増える（相棒 = 5つ目）。上限4は、ユーザーが GAME_BRIEF で決めた数。
- 画像の枚数は増えない（ボスの絵をそのまま使う）。素材のアイコンが4つ増える。
