# F-003 放置は「ためる」行為にする。面は、挑戦ボタンを押すまで進まない

- 日付: 2026-10-11（build-4 を遊んだあと。ログは次に届く）
- 種別: 追加要望（核の循環そのものの変更。契約書の変更を伴う）
- 状態: 承認済み（改訂16〜18）。作り直しで対応する

## ユーザーの言葉（要約せずに残す）

- このゲームの放置要素は、クリアしたステージでリソースをためる行為であって、そのステージを永遠に周回する行為ではない。
- 具体的には:
  - ステージは、プレイヤーが挑戦ボタンを押すまで次に進まない。
  - 放置報酬の単価は、クリアした最終ステージで決まる。
  - 放置報酬を受け取る場所を存在させる。
  - 各ステージには、初クリア報酬を用意する。

## 影響（Claude の見立て）

- 契約書の決定8（勝ったら自動で次へ。負けたら止まり、手前の面で稼ぐ）が変わる。
  戦闘は「挑戦を押したときだけ」起き、それ以外の時間は、開いていても閉じていても同じ速さでたまる。
- 最初の10分の台本を書き直す。合否の数字（初めて負けるまで、進まない時間の最長 など）は、意味が変わるので決め直す。
- S2 で気になっていた点（第2章が「着いたら一度負ける → 稼ぐ → 再挑戦」のくり返しになる、
  稼ぎの戦闘の長さで進む速さが大きく変わる）は、この形にすると元から起きなくなる。
- 模擬プレイの遊び方（いつ挑戦を押すか）を作り直す。
