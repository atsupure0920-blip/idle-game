# F-017 画面を圧迫しない: 絞り込みは1つのアイコン、注意書きは「？」、勧誘の印は10連のときだけ

- 日付: 2026-10-13（build-7 を遊んで）
- 種別: 手触り・見た目
- 状態: build-8 で対応。印を消せる設定は保留リスト

## ユーザーの言葉

- 操作性はなかなか良くなった。
- 団員一覧のレベル順・レア度順・星の指定は、一つのアイコンに収束させて、画面を圧迫しないようにするべき。
- 同じ理由で、ガチャや強化画面などにある注意書きは、まとめて見られるものを各画面にアイコンとして置く。
- ガチャは10連のときだけ赤丸の通知が来るようにし、将来的には、その通知を消せる設定も追加する。

## 対応

- 団員の一覧の上は「団員 n/24」「いまの表示（例: ★3・レベル順）」「⇅」「？」の1行だけにした。⇅ で絞り込みと並び替えのポップアップが開く。
- 団員・編成・相棒・勧誘・ミッションの画面に「？」を置き、注意書きをそこへ移した（画面からは消した）。
  勧誘の「最初の10連の約束」と「★3 確定まで あと N回」は、注意書きではなく今の状況なので、画面に残した。
- 勧誘の赤い印は、通常か高級のチケットが10枚以上あるときだけ。
