# F-006 序盤のステージで止まる設計にはしない

- 日付: 2026-10-11（第2版の台本の案を読んで）
- 種別: テンポ・数値（台本と合否の数字の修正）
- 状態: 案に反映済み（`spec/drafts/`）。承認待ち

## ユーザーの言葉

- この手のゲームって、序盤のステージで止まる設計は基本されないと思う。
- 例えば、チュートリアルのガチャで最高レアが必ず一体出るようになっていたり、そいつを育てればある程度進めるようになっていると思う。
- 今回はそこまで考えないなら、それでいいと思う。

## 対応

- 台本から「5分ごろ、1-7 あたりで初めて負ける」を外した。稽古しながら進めていれば、第1章では負けない。
  初めて負けるのは、第2章の中ほど（15分前後）。稽古のしかたは、負けてではなく、ミッションで覚える。
- 合否の数字: 初めて負けるまで 3〜8分 → 12〜25分。30分後の到達面 14〜20 → 18〜26。相棒になるまで 6〜12分 → 5〜10分。
- 「最初の勧誘で最高レアが必ず出て、その団員が先へ連れていってくれる」は、団員を増やすとき（レア度の中身を入れるとき）に合わせて入れる。
  いまは団員が7人で、レア度を分けると勧誘の中身が薄くなるため。
- 元の案（5分で負ける）は、第1版の「負けて稽古を覚える」をそのまま引きずっていた Claude の誤り。
