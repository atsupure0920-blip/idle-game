# F-020 放置の報酬はプレイヤーレベルの経験値のため。育成素材は、いろいろな場所で手に入るように

- 日付: 2026-10-13（改訂案3への回答に添えて）
- 種別: 追加要望（仕組みの追加と、報酬の配り方の作り直し。契約書の変更を伴う）
- 状態: 改訂案4（`spec/REVISION-4.md` の 53〜58）に入れた。○ ✕ 待ち

## ユーザーの言葉

- 放置ゲームの報酬は何のためにあるかと言えば、一番はプレイヤーレベルの経験値のためだと思う。
- いまはその概念自体がない状態なので、それを追加したい。
- 逆に言えば、現状の放置報酬がメインの育成素材の収集場所になっているのがよくない。
  もっといろんな場所で配布や入手ができるようにならないといけない。

## 読み取り

- F-018（長く離れても、育てられる量が頭打ちになる）と同じ根から出ている。
  いまは「時間 → おひねり → レベル」の一本道で、おひねりの量が進みのほぼすべてを決めている。
- プレイヤーレベルを「時間の価値」の受け皿にし、育成素材は、初クリア・ダンジョン・ミッション・日課など、
  遊んだ行動ごとに配る形にすると、両方を一度に直せる。
- 進む速さの数値と、最初の30分の台本・合否の数字を、まとめて作り直すことになる（第4版）。
