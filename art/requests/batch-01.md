# 依頼 1回目: 見た目の試し（10枚）

最初の約10枚で、絵柄がそろうか、1枚あたりどれくらい手間がかかるかを確かめる。
選んだのは、遊び始めてすぐ目に入るもの（最初の3人、最初の10連で必ず来る2人、1章の敵3種、1章のボス、1章の背景）。

先に `art/ART_GUIDE.md` の「共通の指示」を貼ってから、下を1枚ずつ貼る。
できた絵は、書いてあるファイル名で `art/inbox/` に置く。全部そろわなくても、何枚かたまったら「art-in」と送ってよい。

---

## 1. 大道具係 → `h_stagehand.png`

```
大道具係（★1、盾役）: 劇団の舞台の大道具を担当する、がっしりした体格の青年。
頭にバンダナ、作業用のエプロンと革の手袋。背中に木槌を差している。
両手で、森の絵が描かれた木の板（舞台の書き割り）を盾のように構えている。頼もしい笑顔。
```

## 2. 見習い役者 → `h_apprentice.png`

```
見習い役者（★1、攻撃役）: 劇団に入ったばかりの元気な少年。
少し大きすぎる舞台衣装（ベストと短いマント）を着て、小さな木の剣を振り上げ、もう片方の手に丸めた台本を持っている。
やる気いっぱいの表情。
```

## 3. 呼び込み → `h_barker.png`

```
呼び込み（★1、攻撃役）: お客を呼び込む明るい少女。
チケット柄のベストとキャスケット帽。紙のメガホンを口に当て、もう片方の手に劇団の小さな旗を持っている。
大きく口を開けて、元気に呼び込んでいる。
```

## 4. 花形役者 → `h_star.png`

```
花形役者（★3、攻撃役）: 劇団の看板の若い男性役者。
きらびやかな舞台衣装（やさしいネイビーの上着に金の飾り、白いマント）。細身の剣を高く掲げ、片目をつぶってウインク。
周りに小さなきらめきを少し（いちばん高いレア度らしい華やかさ）。
```

## 5. 衣装係 → `h_costume.png`

```
衣装係（★2、回復役）: 劇団の衣装を作るやさしいお姉さん。
ピーチ色のエプロン、首に巻き尺、腰に小さな裁縫箱。手に大きな針と糸を持ち、糸がふわっと淡く光っている（回復の力）。
にっこり笑っている。
```

```
かかし（敵の魔物）: つぎはぎの服と麦わら帽子のかかし。棒の手を大きく広げ、口はぎざぎざの縫い目。
可愛いけれど、少し意地悪そうで得意げな顔。
```

## 8. おおねずみ（敵） → `e_rat.png`

## 9. もりのくま（1章のボス、あとで相棒） → `c_bear.png`

```
もりのくま（1章のボス。倒すと改心して、劇団の相棒になる）: 大きな茶色のくま。胸に三日月の模様。はちみつの壺を抱えている。
少し怖い顔をしているが、どこか憎めない。ほかのキャラより大きく、堂々とした立ち姿（それでも全身が枠に入るように）。
```
