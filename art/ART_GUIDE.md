# 絵の決まり（S4）

絵は ChatGPT で作ってもらい、Claude がゲームに入れる。全部の絵で絵柄をそろえるための決まりと、名前の一覧。
依頼文は `art/requests/` にまとめてある（1回ぶんずつ）。

## 進め方

1. ChatGPT で新しい会話を開き、下の「共通の指示」をそのまま貼る（会話の最初に1回だけ）。
2. 依頼文を1枚ずつ貼って、絵を作ってもらう。気に入らなければ、直してほしい点を言って作り直してもらう。
3. 気に入った絵は、PNG で保存し、指定のファイル名に変えて、PCの `idle game/art/inbox/` に置く。
   （背景が透明にならなかったときも、そのままで構わない。1色の背景なら、Claude 側で消す）
4. 2枚目からは、気に入った1枚目の絵を添付して「この絵と同じ絵柄で」と添えると、そろいやすい。
5. 何枚かたまったら、チャットで「art-in」と送る。Claude が整えてゲームに入れ、遊べるビルドにする。

## 共通の指示（会話の最初に貼る）

```
これから、スマホ向けの放置RPG「旅の劇団」の絵を1枚ずつ頼みます。すべて同じ絵柄でそろえてください。

【絵柄】やさしく可愛いデフォルメ。2.5頭身前後、頭大きめ・手足短め、全体は丸く柔らかい形。
線は濃いブラウン（#6A5242）でやや太め、外周を少し太く、内側の線は細め。
塗りはアニメ塗り寄りの1段影（必要なら2段目を少しだけ）。グラデーションは控えめ。目と髪に小さく柔らかいハイライト。
【色】クリーム、ベージュ、ピーチピンク、ブロンド、やさしいネイビー、空色を中心にした、明るいパステル調。
【避けること】黒すぎる線、厚塗り、強いコントラスト、リアル寄りの表現。

【キャラクターの形式】正方形（1024×1024）、背景は透明のPNG。キャラクター1体だけ、全身を頭から足先まで切らずに入れる。
周りに少し余白を残す。文字、ロゴ、枠、地面の影は入れない。体はやや斜め（3/4）、顔はこちら向き。
```

## 気をつけること

- 画面の飾り（ボタンや枠の絵）は、配置がまだ変わるので、あとで作る。
- 1枚の大きさは、ゲームに入れたあとで 200KB 以下にする（Claude 側で縮める）。
- 生成した絵を使ってよい範囲は、ChatGPT の利用規約に従う（公開して遊んでもらう用途で使う）。
